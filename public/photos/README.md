# Community Manager Photos

Place community manager photos in this folder.

## Naming Convention

Photos should be named exactly as the person's name in lowercase, with `.jpg` extension:

- `sonet.jpg`
- `fatin.jpg`
- `sajid.jpg`
- `mahmud.jpg`
- `sifat.jpg`
- `naeem.jpg`
- `mahdy.jpg`
- `mongchaw.jpg`
- `sabbir.jpg`
- `toufiq.jpg`
- `dummy.jpg` (for dummy entries)

## Supported Formats

- `.jpg` (recommended)
- `.jpeg`
- `.png`

## Example

If you have a photo for Sajid, name it: `sajid.jpg`

The application will automatically load photos from this folder using the path: `/photos/[name].jpg`
